# Smart Technical Services (STS)

**Intelligent systems. Safer spaces. Smarter futures.**

Smart Technical Services (STS) is a responsive business website designed to showcase integrated technical solutions, manage customer enquiries, and provide an administrative interface for managing website content and business operations.

## Features

- **Responsive Website:** Modern UI/UX for desktop, tablet, and mobile devices.
- **Solutions Showcase:** Dedicated sections for fire safety, security systems, audio-visual solutions, building management, and specialized technical services.
- **Projects Portfolio:** Visual project cards with interactive elements and detailed project information.
- **Customer Authentication UI:** Combined login and signup interface with password visibility controls.
- **Customer Portal:** Customer details and enquiry viewing.
- **Enquiry Management:** Admin dashboard for reviewing and managing customer enquiries.
- **Priority Controls:** Assign High, Medium, or Low priority to enquiries.
- **Admin Dashboard:** Centralized interface for managing enquiries, customers, projects, services, and careers.
- **Interactive UI Effects:** Image slideshows, graphic shadows, texture overlays, animations, and glowing navigation elements.
- **Contact Integration:** Contact forms and enquiry actions to help customers connect with the business.

## Technologies

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Launch `index.html` using Live Server.
4. Explore the website, customer interface, and admin dashboard.

## Important Note

The current front-end prototype uses browser storage for certain customer and enquiry records. Production deployment requires secure backend authentication, a database, server-side validation, and appropriate access controls.

## Project Purpose

To provide a professional digital presence for STS while making technical services easier to explore and customer enquiries easier to manage.
